v1 is rather minimal, it includes the following features and/or properties:
- 3x qwiic connectors
- 5x gnd and 5x 3.3v (i never want to run out of these again)
- all module's pins accesible
- usb c 2.0 charging and data in (data from esp32 likely doesn't work, untested)
- rst/boot buttons
- 2x rgb led (second may not work, untested)
- dimensions (exc height) of a credit card
- fast charge toggle
- charge/pwr indicator leds and brakeout
